# orc-crds

Helm chart for installing the [OpenStack Resource Controller (ORC)](https://k-orc.cloud/) Custom Resource Definitions.

This chart installs only the CRDs. Install the [orc](../orc/) chart separately to deploy the controller.

## Install

```bash
helm install orc-crds oci://quay.io/orc/helm/orc-crds --version <version>
```

## How CRDs are managed

The `crds/` directory is a symlink to `config/crd/bases/`, so no copying or
generation step is needed. The CRD files themselves are generated by
`controller-gen` via `make manifests`.
