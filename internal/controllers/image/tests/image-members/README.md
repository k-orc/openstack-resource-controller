# Share an image with projects

## Step 00

Create a shared image with one member and verify that the member is pending.

## Step 01

Replace the member and verify that the image has only the new one.

## Step 02

Replace the member with a project which does not exist yet and verify that the old member is removed while the image waits for the project.

## Step 03

Create the project and verify that it is added as a member.

## Step 04

Remove all members and verify that the image has none.
