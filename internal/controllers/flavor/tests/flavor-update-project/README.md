# Update Flavor with Projects

## Step 00

Create a Flavor using only mandatory fields.

## Step 01

Create a Project and add this Project to the Flavor. Verify that the Project has been added to the Flavor in OpenStack successfully.

## Step 02

Create another Project and add this Project to the Flavor. Verify that the Project has been added to the Flavor in OpenStack successfully.

## Step 03

Delete one of the Projects from the Flavor. Verify that only that specific Project is no longer in the Flavor in OpenStack.

## Step 04

Revert the resource to its original value and verify that none of the Project remain in the Flavor.
