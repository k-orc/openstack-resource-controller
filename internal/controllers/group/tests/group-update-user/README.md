# Update Group with Users

## Step 00

Create a Group using only mandatory fields.

## Step 01

Create a User and add this User to the Group. Verify that the user has been added to the group in OpenStack successfully.

## Step 02

Create another User and add this User to the Group. Verify that the user has been added to the group in OpenStack successfully.

## Step 03

Delete one of the Users from the group. Verify that only that specific user is no longer in the group in OpenStack.

## Step 04

Revert the resource to its original value and verify that none of the users remain in the group.
