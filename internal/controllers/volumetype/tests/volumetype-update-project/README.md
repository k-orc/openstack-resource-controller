# Update Volumetype with Projects

## Step 00

Create a Volumetype using only mandatory fields.

## Step 01

Create a Project and add this Project to the Volumetype. Verify that the Project has been added to the Volumetype in OpenStack successfully.

## Step 02

Create another Project and add this Project to the Volumetype. Verify that the Project has been added to the Volumetype in OpenStack successfully.

## Step 03

Delete one of the Projects from the Volumetype. Verify that only that specific Project is no longer in the Volumetype in OpenStack.

## Step 04

Revert the resource to its original value and verify that none of the Project remain in the Volumetype.
